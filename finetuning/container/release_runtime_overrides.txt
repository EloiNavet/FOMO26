# gardening-tools: the lockfile resolves 0.3.5, but every FOMO26 downstream segmentation
# checkpoint was trained in a Jean-Zay environment carrying 0.3.2. Between those releases
# ResidualUNetDecoder's parameters were renamed from `decoder_conv1..5` / `upsample1..5` to a
# `decoder_convs` ModuleList and `upsample_layers`. The architecture is unchanged, so the weights
# load by shape but not by NAME: all 50 decoder tensors silently miss, the encoder's 450 load, and
# `assert successful > 0` in base_module lets a half-random model through. Such an image builds,
# passes the official validator, meets the runtime budget, and predicts background on every voxel.
# Pinning the version that trained the weights is what makes the packaged model the trained model.
# This is a packaging correction, not a change of model, objective, checkpoint or inference policy.
